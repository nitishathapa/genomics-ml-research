# Genomics ML Research

This project explores computational genomics and machine learning approaches for identifying, prioritizing, and interpreting clinically relevant genomic variants, genes, and biomarkers using public datasets.

## Current Focus

The project is currently in the research and scoping phase. The immediate goal is to identify a biologically meaningful and computationally tractable research question that can be developed into a reproducible genomics + machine learning workflow.

## Candidate Research Directions

1. ML for genomic variant detection or quality prediction
2. ML-assisted prioritization of clinically relevant variants, genes, or biomarkers
3. AI/LLM-based evaluation or interpretation of genomic evidence

## Project Goals

- Work with public genomic datasets
- Build a reproducible computational genomics workflow
- Strengthen Python, Linux, Git, and genomic data analysis skills
- Apply statistical and machine learning methods where scientifically appropriate
- Compare models against meaningful baselines
- Analyze biological and technical failure modes
- Develop the project toward a research-quality study suitable for future academic work

## Planned Workflow

Research question  
→ literature review  
→ dataset selection  
→ genomic data processing  
→ exploratory analysis  
→ baseline method  
→ ML/statistical modeling  
→ evaluation  
→ biological interpretation  
→ reproducibility  
→ final research write-up
